# GitHub CLI

面向「管理本机 GitHub CLI（`gh`）」的插件：它位于哪里、是什么版本、是否已登录、
装了哪些扩展，以及允许 agent 执行哪些 `gh` 命令，都由这个插件负责。

## 0.1.0 版本做什么

什么都不做。当前版本只是脚手架：插件会被激活，但不注册 agent 工具、不启动进程、
不打开任何面板。启用或禁用它都不会改变应用里的行为，因此在能力建设期间可以安全地
保留安装。

本轮只把包结构定下来：bundle 清单、patch 条目、展示元信息、图标和详情文档。

## 计划中的行为

后续版本预计按以下顺序补齐：

1. 只读状态动作：可执行文件路径、`gh --version`、`gh auth status`、
   `gh extension list`、`gh config list`。
2. `run` 动作：在可配置子命令白名单与输出、时长限制下执行 `gh <子命令> …`。
3. 插件配置项：可执行文件名、白名单、超时、捕获输出上限、是否在工作目录执行。
4. 视需要增加 Web UI 面板，复用同一批操作。

以上均未实现，接口仍可能调整。

## 配置

bundle 插入一行 `config: {}` 的插件条目。0.1.0 没有声明任何配置字段，此时你在
那里写的键都会被忽略。

## 本版本限制

- 插件不读取、修改、安装或升级 `gh` 本体。
- GitHub 凭证仍由 `gh` 自己保管，插件不存储任何机密。
- 不注册任何 Web UI 挂载点。
